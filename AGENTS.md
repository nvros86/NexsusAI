# Правила разработки NexsusAI

## Обязательные правила

### После каждого этапа:
1. Запустить `./gradlew build` локально
2. Запустить `./gradlew test`
3. Запустить `./gradlew lint`
4. Исправить все ошибки компиляции
5. Исправить все ошибки тестов
6. Исправить все ошибки линтера
7. Запушить изменения на GitHub
8. Дождаться зелёного CI (build + test + lint)
9. Только после этого приступать к следующему этапу

### При каждом коммите:
- Не коммитить код с ошибками компиляции
- Не коммитить сломанные тесты

### При возникновении ошибки в CI:
- Срочно исправить до продолжения работы
