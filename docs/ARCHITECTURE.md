# NexsusAI Architecture

## Core Principles

NexsusAI is built as a modular AI workstation.

## Modules

### App Layer
User interface and workstation experience.

### Core Layer
Shared infrastructure:

- API abstractions
- local storage
- domain models
- security
- event system

### AI Engine
Responsible for:

- model providers
- AI sessions
- context handling
- memory
- orchestration

### Agent Framework
Provides autonomous workflows:

- coding agent
- task agent
- automation agent

### Plugin SDK
Allows external extensions and AI provider modules.

## Future Goals

- multi-agent collaboration
- local model support
- secure API key storage
- project-aware AI assistance
