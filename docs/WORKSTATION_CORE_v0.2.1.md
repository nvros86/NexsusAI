# NexsusAI Workstation Core v0.2.1

## Цель этапа
Переход от прототипа UI к управляемой архитектуре рабочей среды.

## Реализуется

- MVVM структура
- SessionManager для независимых AI-сессий
- модель WorkSession
- управление вкладками
- подготовка слоя хранения данных

## Архитектура

UI (Compose)
↓
ViewModel
↓
SessionManager
↓
Repository
↓
Storage

## WorkSession

Каждая вкладка представляет отдельный контекст:
- уникальный ID
- название
- выбранная модель AI (будет подключено позже)
- история сообщений
- настройки контекста
